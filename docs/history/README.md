# Historical documents

[Current documentation](../en/index.md) · [Español de España](README.es.md)

These files are retired documentation and evidence, not current instructions. Old plans, specifications, Python/SQLite prototypes, research and probe fixtures now live here rather than in the active documentation folders. Their original bytes and permission modes are preserved, including uncommitted operator edits. They deliberately retain their original language.

## Locate an original

[archive.json](archive.json) maps each original path to its archived copy, SHA-256, permissions and source HEAD blob when available. A HEAD blob is provenance, not a claim that the archived working-tree bytes match that commit. The documentation check verifies every archived file against its recorded bytes and mode.

Relative links and commands inside the originals describe their original layout and checkpoint. They are preserved evidence, not working-tree navigation. For an existing pinned job, use its original path at its own full Git SHA with `git show FULL_SHA:original/path.md`. Do not substitute an archived copy or a current guide for missing pinned input. Do not replay old commands or grants.
