# Verify original local evidence during native review

For an original local evidence check, the workspace may additionally contain `evidence: {path, sha256}`. The external grant must bind that identical descriptor and set `allowOriginalEvidence: true`. Only a separate canonical path below `/tmp` or `/var/tmp` is supported. Its complete regular-file tree, modes and content hashes are checked before and after every probe, with at most 4096 entries and 64 MiB. Symlinks, multiply linked regular files and special files are refused, including inside the optional source object database. Source, target, input, store, reviewer checkout, grant and authentication paths cannot overlap it. The runtime mounts only this explicitly approved evidence path read-only at its original absolute location. It remains host-selected command input, not model filesystem access. If the original fixture uses Git alternates pointing to this factory's object database, add `sourceObjectsSha256` to the evidence descriptor and explicitly grant `allowSourceObjects: true`. The runtime then hash-checks and mounts only its own `.git/objects` directory read-only at its original path. No other source Git metadata, home or authentication files become visible. The object database has the same entry, byte and deadline bounds. Without both the pin and grant this extra mount is refused. An absent descriptor retains the existing isolated-checkout behavior. A changed pin blocks before the provider call; a missing original fixture is not fixed by copying or replaying a worker.

The supplied model evidence includes the caller-verified current assignment and matching authorization fields, including input and candidate pins and any evidence descriptor. Authentication locators and credentials are omitted. These operator-owned grants are not authenticated actor identities or permission for model-selected tools.

Use this optional contract with the existing assignment, external grant and caller described in [Model routing](model-routing.md#dispatch-an-independent-reviewer). It supplies host-selected observations, not model tools or proof of arbitrary archive authenticity. No worker, reboot, retry or publication is authorized by an evidence mount.
