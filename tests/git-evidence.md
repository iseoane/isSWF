The initial identity implementation predates the operator's TDD selection. A later linked-pack refusal regression was observed failing before its production correction and passing afterwards; an earlier fixture failure caused by a leftover alternates file was not a behavioral red result. These facts do not claim red-first evidence for the initial implementation.

The CLI and Pi tests use temporary fixture repositories/profiles and clean only their owned temporary roots. The native reviewer acceptance step must be a fresh Pi reviewer launch with the explicit trusted binding shown in `.agents/hosts/pi.md`; coordinator-supplied output and these fixtures do not satisfy it.
